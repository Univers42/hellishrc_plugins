# devkit

devkit: project detection, universal run/build/test/fmt/lint

**Group:** dev  
**State:** on  

## Enable

```sh
conf on devkit && conf reload
```

## Provides

| kind | name | usage | description |
|---|---|---|---|
| func | `build` | `build [args]` | build this project, whatever kind it is |
| func | `fmt` | - | format this project's source |
| func | `lint` | - | lint this project |
| func | `proj` | - | describe the project you are standing in |
| func | `proj_root` | - | nearest directory above here that looks like a project |
| func | `proj_type` | `proj_type [dir]` | detect the project type of a directory |
| func | `run` | `run [args]` | run this project |
| func | `scratch` | `scratch [extension]` | open a timestamped scratch file in $EDITOR |
| func | `test_` | `test_ [args]` | test this project (named test_ so it never shadows the 'test' builtin) |
