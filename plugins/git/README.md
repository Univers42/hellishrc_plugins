# git

git: repo status, safe undo, wip commits, branch cleanup

**Group:** vcs  
**State:** on  
**Requires:** `git`  

## Enable

```sh
conf on git && conf reload
```

## Provides

| kind | name | usage | description |
|---|---|---|---|
| func | `gbranch` | - | print the current branch name |
| func | `gfind` | `gfind <string>` | find commits that added or removed a string |
| func | `ginfo` | - | one-screen repository overview: branch, drift, counts, recent log |
| func | `gnuke` | - | discard every local change (shows them and asks first) |
| func | `groot` | - | cd to the repository root |
| func | `gsw` | `gsw <branch>` | switch to a branch, creating it if needed |
| func | `gsweep` | - | delete local branches already merged into the default branch |
| func | `gundo` | - | undo the last commit, keeping its changes staged |
| func | `gunstage` | `gunstage [path...]` | unstage everything, or the given paths |
| func | `gunwip` | - | undo the last wip commit (refuses if it is not one) |
| func | `gwhen` | `gwhen <file>` | history of one file, following renames |
| func | `gwho` | `gwho [rev-range]` | commit counts per author |
| func | `gwip` | - | commit everything as a timestamped wip (skips hooks) |
| var | `HX_GIT_AUTOINFO` | - | set to 1 to run ginfo automatically on entering a new repo |
