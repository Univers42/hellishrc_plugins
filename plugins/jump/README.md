# jump

jump: frecency directory jumping, bookmarks, back-stack

**Group:** nav  
**State:** on  

## Enable

```sh
conf on jump && conf reload
```

## Provides

| kind | name | usage | description |
|---|---|---|---|
| func | `j` | `j <fragment>` | jump to the best-scoring directory matching a fragment |
| func | `jclean` | - | drop dead paths and prune the jump database |
| func | `jl` | `jl [fragment]` | list jump candidates and their scores |
| func | `jrm` | `jrm <fragment>` | forget jump entries matching a fragment |
| func | `mark` | `mark [name]` | bookmark the current directory |
| func | `marks` | - | list bookmarks |
| func | `to` | `to <name>` | jump to a bookmark (no argument lists them) |
| func | `unmark` | `unmark <name>` | remove a bookmark |
| var | `HX_JUMP_DB` | - | frecency database for the jump plugin |
| var | `HX_JUMP_MAX` | - | how many directories to remember before pruning |
