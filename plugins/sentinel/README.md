# sentinel

sentinel: system dashboard, disk/load/memory watch, repo scan

**Group:** sys  
**State:** on  

## Enable

```sh
conf on sentinel && conf reload
```

## Provides

| kind | name | usage | description |
|---|---|---|---|
| func | `repos` | `repos [dir]` | git repositories below a directory with uncommitted changes |
| func | `sentinel` | - | the full system dashboard |
| func | `sys_disk` | - | disk usage per mount, with bars |
| func | `sys_load` | - | load average and uptime |
| func | `sys_mem` | - | memory and swap usage |
| func | `sys_top` | - | the five hungriest processes |
| var | `HX_SENTINEL_DISK_WARN` | - | disk %% at which sentinel warns (default 90) |
| var | `HX_SENTINEL_WATCH` | - | set to 1 to warn once per shell when a disk crosses the threshold |
